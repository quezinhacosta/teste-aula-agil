## Como ler o campo “front/back/projeto”

- front: fala diretamente com interface e interação
- back: fala com regras, persistência e operações principais
- data/banco: modela estrutura ou consultas centralizadas
- projeto/doc: organiza projecto, docs, issues e decisões
- prototipagem: protótipos para validação, não sistema final
- coordenação: alinha frentes e checkpoints
- infra: ambiente, segurança, desempenho, disponibilidade
